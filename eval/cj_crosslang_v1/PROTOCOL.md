# CJ 中文需求跨语言检索实验 v1

## 冻结范围

- 基线代码：`30b9a4f`；商品：`eval/cj_v1/snapshot.json` 指定的只读 CJ SQLite 快照；原有回归集：`eval/cj_v1/retrieval_cases.jsonl` 40 题。
- 开发集：原有中文改写 8 题，ID 与锚点保持不变；`dev_cases.jsonl` 只补分层和人工理想英文检索词。分层为字面属性 2、混合型号 1、功能描述 1、单位换算 1、同义表达 1、口语表达 1、材质与功能 1。原 8 题中 `CJ-R031/032` 虽标记为 `release`，其结果已公开，故在本实验中一律视为开发题。
- 封存集：`holdout_cases.jsonl` 10 题，锚点均不在原 40 题中；属性 2、功能 2、对象同义 1、中文加英文规格 2、多属性 3。只用快照标题验证锚点存在和支持词，不在代码/参数冻结前运行检索或 Agent，不因本轮结果修改题面、锚点和分层。封存后记录 SHA-256；任何变化使本轮对比无效。
- 每题一个人工核验的指定商品锚点。它不是穷举相关商品；所有 Hit@K、MRR 都只针对锚点，不称完整 Recall 或答案准确率。无结果误召回用原 40 题的四道 `empty` 题测。

## B：诊断基线

同一快照逐题运行开发集。每题三种查询：中文原文、Agent 在**完整主 Agent 链路**的首次 `product_search_tool` 调用中产生的 `normalized_query`、预先写定的 `ideal_query`。三种查询都分别在 `category=None` 和 Agent 实际传入且经工具归一化后的 `category` 下调用 CJCatalog；若 Agent 无商品检索调用，则标记 `no_search_call`，不得伪造 normalized_query。人工理想词只作诊断上限，不作为生产答案或留出题提示。Agent 原始结果还需单独记录，不能用离线重放结果冒充完整链路表现。

主 Agent 每题使用全新 buyer/session，输入原题，不附锚点、英文词或品类；禁用语义缓存，固定模型、提示词版本、温度等可观测配置。保留所有工具调用、参数、结果 ID 顺序、最终答复和调用错误；将可能触发写操作或 CJ 实时调用的题目限制为普通商品检索请求，并核对实际工具。离线重放只读快照，CJ 点数与模型 token 均为 0；Agent 调用成本另记，不能混算。

每种查询及品类开关记录锚点 `rank`、Hit@1/3/5、MRR；展示分子分母。若单题多次 Agent 检索，记录全部调用，主要口径为首次；另报任一次前五命中。记录模型请求数、输入/输出/总 token（若提供方没有 usage 则写 `unknown`）、CJ 在线调用数、工具错误数和端到端耗时。记录快照 SHA-256、题集 SHA-256、Git commit、工作树指纹、模型/提示词标识与运行时间。

## C：单一首故障层归因

仅对目标锚点未被最终正确采用的题归因，沿数据流标记第一个有证据的故障层：

1. `rewrite`：Agent 未调用商品检索、丢失关键实体/约束，或其无品类查询未命中而人工理想英文查询能命中。
2. `category`：同一 Agent 查询关闭品类能命中，打开实际品类后丢失锚点。
3. `retrieval`：人工理想英文查询关闭品类仍无候选锚点；须检查快照锚点与标题是否仍有效。
4. `ranking`：锚点在更深候选中但不在前五，且查询与品类均可接受。
5. `selection`：锚点在 Agent 检索返回前五，模型选了别的商品或没有选商品。
6. `answer`：模型选择了锚点，却在答复中错误陈述其关键属性、证据或报价边界。

有多个现象时仅计最早一层；证据不足记 `unattributed`，不把未知硬归因。按层统计数量、占失败题的比例和逐题证据，再决定主要改动层。开发集只能用于选方案，封存集不用于调参。

## D—F：改动、闸门和下一轮

一次只改主要故障层。顺序按观测证据选择：查询归一化、品类处理、词法检索/排序、混合或向量检索。前后必须固定同一快照、题序、Agent 模型和提示词配置；模型随机性使 Agent 指标只能作为重复观测，不能宣称因果确定性。

初步成功闸门：开发集首次 Agent 查询的已知商品 Hit@5 至少净增 2/8，原 40 题通过数不低于修复前的 34/40，原有 `exact` 4/4、`empty` 至少 3/4 不下降；不得出现已知商品的错误报价或无证据到手价。若开发集未达标，不能打开留出集评估泛化。若达标，代码及参数冻结后在同一时点**一次**运行封存集的前后版本，要求净增至少 2/10 且无严重答案事实错误，才称本轮具备初步泛化证据。单题退化、所有失败层和成本变化仍逐一披露；小样本阈值是事先约定的实验门槛，不是统计显著性。

最终报告列 baseline commit、fix commit、输入哈希、逐题 diff、Hit@1/3/5、MRR、失败归因、Agent token/调用数、CJ 点数及验证范围。若留出不达标，不再用这 10 题调本轮参数；将其升级为已知测试集，下一轮重新建立未见过的留出集。
