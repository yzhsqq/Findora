# CJ 物流试算小范围验收（2026-09-29）

## 范围与取样

- 使用隔离的 `data/cj_pilot/cj_catalog.sqlite3`，没有覆盖原始 CJ 快照。
- 从 9 个类目轮流选取 20 件此前仅有列表信息的商品；列表快照的 `warehouseInventoryNum` 大于 0。这个字段包含工厂备货，只用于取样，不能证明当前规格有 CJ 仓现货。
- 每件先向 CJ 查询商品详情，再**明确选取返回的第一个 SKU 作为测试规格**，数量 1、目的国 CN；随后查询库存与 CJ 物流报价。真实用户在网页上遇到多规格商品时必须自行选择，网页不会自动使用第一个规格。
- 本轮新增积分预算 650 点；试运行库的每日积分硬上限 1,000 点。

例如，商品 `1377823658046787584` 的测试 SKU `CJSG106311401AZ` 发往 CN，CJ 返回已知费用试算合计 **US$7.70**。商品 `2411050909311603800` 的测试 SKU `CJSJ218294901AZ` 返回 **US$271.96**，说明运费需要按具体规格和线路查，不能由商品列表价推断。两件无线路的商品只能说明**本次** CJ 未返回可用线路，不能断言永久无法配送。

**纠偏：**本批 17 个成功结果均为工厂备货 SKU，不能表述为“CJ 仓现货已核验”。测试目的国固定为 CN，库存来源国家也均为 CN，因此结果是同国物流试算，不能作为跨境运费样本。CJ 的报价接口确实返回了这些费用，但起运国是程序按库存记录传入的试算参数；实际发货地点、订单可用线路与最终费用仍需在下单阶段核对。

详细的 20 件结果保存在本机 `data/cj_pilot/quote_acceptance.json`，包含商品 ID、测试 SKU、结果或失败原因，不包含 API Key 和令牌。这个数据目录未纳入 Git。

## 页面与价格边界

列表商品的试算入口现在可点击：点击后按需拉商品详情；单规格继续试算，多规格先请用户选择；报价成功后页面更新本地库存查询时间。后端使用 10 分钟详情与库存缓存、5 分钟物流报价缓存，并对点数消耗设硬上限。

CJ 返回的是商品规格价格加物流接口列出费用的**试算合计**。未确认的税费、清关费用、详细地址及最终订单价格仍不能算作已覆盖；页面继续标明“非最终支付价”。
